# APP1_Backend — School 21

Два учебных backend-проекта на Python: Flask, SQLAlchemy и PostgreSQL.

| Проект | Содержание | Как запустить |
|---|---|---|
| [Backend 04](project04/) | Basic Auth, хранение пользователей и игр, игра вдвоём/против компьютера, браузерный интерфейс | [Инструкция](project04/RUN.md) |
| [Backend 05](project05/) | JWT access/refresh, история игр и таблица лидеров | [Инструкция](project05/RUN.md) |

В каждом проекте `src/` содержит реализацию, `README_RUS.md` — исходное задание.
Проекты запускаются отдельно. Для демонстрации начните с Backend 05.
